# Runbooks

Kịch bản kiểm thử tay và quy trình vận hành — những thứ không tự động hóa được.

Bắt đầu viết từ Phase 5.

## Dự kiến

| File | Nội dung |
|---|---|
| `REAL_DEVICE_CALL_E2E.md` | Kịch bản gọi video thật giữa hai máy, hai mạng khác nhau: các bước, kết quả mong đợi, chỗ hay hỏng |
| `PRODUCTION_READINESS.md` | Checklist trước khi demo/bảo vệ: service nào phải chạy, dữ liệu mẫu nào phải có, cấu hình nào phải đúng |
| `DEMO_SCRIPT.md` | Kịch bản demo trước hội đồng: thao tác theo thứ tự nào, phòng hờ gì nếu mạng hỏng |
