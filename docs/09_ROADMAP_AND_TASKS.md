## 1. Hướng dẫn Sử dụng Tài liệu này

Tài liệu chia công việc theo 8 giai đoạn (Phase). Mỗi task có ID dạng Pn-Txxx, phụ thuộc (task nào phải xong trước), và giờ ước tính. Khi bắt đầu một task, mở đúng tài liệu tham chiếu liệt kê trong cột 'Tài liệu tham chiếu' — không cần đọc tài liệu nào khác.

- P0: Setup môi trường — làm 1 lần, không lặp lại

- P1: Database schema — nền tảng cho mọi thứ, làm trước khi viết 1 dòng code backend

- P2: Backend API — làm theo thứ tự module, mỗi module test ngay bằng Postman

- P3: Signaling Server — viết độc lập, nhỏ, song song P2 cuối phase

- P4: Frontend — theo thứ tự màn hình SCR-01→SCR-20 trong UI/UX Design

- P5: Integration — kết nối tất cả, chạy Test Cases

- P6: Performance Test — đo thực tế và điền Performance Report

- P7: Hoàn thiện — báo cáo, slide, demo

*Quy ước cột 'Ước tính': giờ làm việc thực tế (không tính thời gian học). Tổng ước tính toàn dự án: ~280–320 giờ.*
